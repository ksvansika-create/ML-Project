01 — Abstract

Treat shoppers as groups, not a crowd.

Customer segmentation divides a base into groups that share similar traits. This project applies two unsupervised methods — K-Means and agglomerative Hierarchical clustering with Ward linkage — on mall customer data. Features are cleaned and standardized so distances stay fair. Optimal K is chosen with the Elbow method and checked with the Silhouette score. Hierarchical clustering builds a dendrogram that shows how customers merge. The result: segments such as high-income high-spenders, budget-conscious shoppers, and core regulars — useful for campaigns, offers, and retention.

  • Discover Find natural groupings with no pre-labelled classes.
  • Compare Run K-Means and Hierarchical clustering on the same data.
  • Act Map each segment to a marketing or retention move.

05 — Method

How the two algorithms differ.

Pre-processing

Pandas loads Mall_Customers.csv. Age, income, and spending score go through StandardScaler so income does not dominate Euclidean distance.

K-Means

Python KMeans (scikit-learn, K-Means++, random_state=42) partitions customers into K groups that minimize intra-cluster variance. Best K follows the Elbow kink, checked with Silhouette.

Hierarchical (Ward)

SciPy linkage(..., method="ward") merges customers to keep variance low. fcluster cuts the dendrogram at K groups. The plot in the lab is that same tree.

Visualization

Primary view is income vs spending. The PCA view uses sklearn.decomposition.PCA on the three scaled numeric features.

K-Means is efficient. Hierarchical is interpretable. Together they give a complete view for targeted marketing.
